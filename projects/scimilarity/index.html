SCimilarity — a search engine for cells

Query a cell, and SCimilarity returns its nearest neighbors across a reference of 23.4 million cells.

Think of it as reverse image search for cells: hand the model a cell, and it returns every similar cell we've ever seen — along with the tissue, disease, and context that came with them. The question behind this is deceptively simple: have we ever seen a cell like this before, and if so, in what tissue, what disease, what context? Single-cell sequencing has produced enormous public and internal datasets, but almost nobody was asking that question at scale. Information retrieval — the thing that makes web search and protein search possible — barely exists yet for single-cell genomics. That's still true today; it remains one of the most underdeveloped areas of the field, with very few tools or benchmarks built around it.

Answering it meant solving three problems at once: collecting data at a scale nobody had assembled for this purpose, curating consistent metadata across studies that were never designed to be compared, and designing a model architecture around metric learning rather than the classification or generative objectives most single-cell models use. The result, published in Nature (2025), is a foundation model that turns "what is this cell" into a search problem — embed a cell, find its nearest neighbors across a reference of millions of cells, and read off the biological context that comes with them.

SCimilarity is now built into Genentech's standard compute environments, has an internal community of roughly 130 people, and its outputs — similarity searches, embeddings — show up in governance decisions and target nomination work, not just as a research artifact.

The full reference dataset spans nearly every tissue and disease state represented in public single-cell data.

Heimberg, G., et al. A cell atlas foundation model for scalable search of similar human cells. Nature, 2025.
